# View Yield

View Yield 是用户在 SuperFlow Protocol 中查看收益结果、收益率、历史收益与凭证数据的页面。

在 SuperFlow 中，收益不是一个孤立数字，而是由资金状态、参与周期、交易执行、风险控制与凭证系统共同记录的系统结果。

## 核心定义

View Yield = 收益展示 + 历史记录 + 收益解释 + 凭证入口

它的目标，是让用户不仅看到收益结果，也能理解收益来源、参与状态、执行记录与验证路径。

## 用户可以看到什么？

用户进入收益页面后，可以查看以下信息：

  </Card>

  <Card title="历史收益" icon="activity">

  </Card>

  <Card title="参与资金" icon="wallet">
    展示参与本金、可用资金、冻结资金与周期状态。
  </Card>

  <Card title="收益凭证" icon="shield-check">
    展示交易凭证、订单信息、成交信息与查询链接。

</CardGroup>

## 收益页面的核心字段

| 字段 | 说明 |
| --- | --- |
| Total Capital | 用户参与系统的总资金 |
| Available Capital | 当前可用资金 |
| Active Capital | 当前正在参与系统调度的资金 |
| Current Yield | 当前收益 |
| Historical Yield | 历史累计收益 |
| Yield Rate | 收益率 |
| Cycle | 当前参与周期 |
| AGENT Status | SUPER AGENT 当前状态 |
| Risk Status | 当前风险状态 |
| Voucher Status | 收益凭证生成状态 |

## 查看收益流程

<Steps>
  <Step title="进入账户中心">
    用户登录 SuperFlow 后，进入 Dashboard 或 Yield 页面。
  </Step>

  <Step title="查看当前收益">
    页面会展示当前收益、收益率、参与资金和当前周期状态。
  </Step>

  <Step title="查看历史收益">
    用户可以进入历史记录，查看不同周期、不同交易或不同资产的收益情况。
  </Step>

  <Step title="查看收益凭证">
    用户可以点击收益记录中的凭证入口，查看对应交易凭证和验证信息。
  </Step>

  <Step title="理解收益来源">
    用户可以通过订单价格、成交数量、平台信息、平仓原因和查询链接理解收益来源。
  </Step>
</Steps>

## 收益是如何形成的？

SuperFlow 的收益来自真实市场行为，不是简单内部数字分配。

收益形成流程可以理解为：

```text
资金进入系统
  ↓
SUPER AGENT 识别机会
  ↓
Smart Routing 优化路径
  ↓
Execution Layer 完成真实交易
  ↓
Yield System 记录收益
  ↓
Verification System 生成凭证
```

## 收益计算逻辑

在 SuperFlow 中，收益不是只由本金决定。

收益可能受到以下因素影响：

| 变量 | 说明 |
| --- | --- |
| Capital | 用户参与资金规模 |
| Time | 用户参与周期和资金持续时间 |
| Permission | 用户权限、等级与系统参与深度 |
| Market Capability | 系统识别交易机会的能力 |
| Execution Quality | 智能路由与执行层带来的执行质量 |
| Risk Control | 风控系统对回撤、异常和亏损的限制能力 |

收益可以被理解为：

```text
收益 = 资金 × 时间 × 权限 × 市场能力 × 执行质量 × 风控能力
```

这不是固定收益承诺，而是对收益形成过程的系统化表达。

## 收益状态说明

收益页面可能显示不同状态：

| 状态 | 说明 |
| --- | --- |
| Pending | 收益正在计算或等待交易结果确认 |
| Active | 当前周期正在运行中 |
| Settled | 当前收益已经结算 |
| Verifying | 收益凭证正在生成或同步 |
| Completed | 收益记录与凭证已完成 |
| Protected | 因风控、异常或系统保护暂停收益更新 |
| Failed | 交易失败或收益记录异常 |

## 历史收益记录

历史收益记录用于帮助用户查看过去的交易和收益情况。

一条完整的历史收益记录应该包含：

| 字段 | 说明 |
| --- | --- |
| Asset | 交易资产 |
| Direction | 交易方向 |
| Entry Price | 开仓价格 |
| Exit Price | 平仓价格 |
| Size | 成交数量 |
| PnL | 盈亏结果 |
| Yield Rate | 收益率 |
| Close Reason | 平仓原因 |
| Platform | 执行平台 |
| Created At | 交易时间 |
| Voucher Link | 收益凭证入口 |

## 用户应该如何理解收益？

用户不应该只看收益数字。

更重要的是理解：

```text
这笔收益来自哪笔交易？
交易什么时候发生？
在哪个平台执行？
开仓和平仓价格是多少？
收益率是多少？
有没有凭证？
是否能查询？
是否有风险提示？
```

SuperFlow 的收益展示目标，是让收益结果更透明、更可解释、更可验证。

## 收益和风险的关系

收益和风险必须一起理解。

真实交易存在市场波动、价格滑点、执行失败、流动性不足、平台异常、策略失效和本金亏损风险。

因此，收益页面不仅应展示收益，也应该展示：

- 风险状态
- 风控触发
- 平仓原因
- 执行异常
- 收益波动
- 凭证状态

## 常见问题

### 为什么收益还没有更新？

可能原因包括：

- 当前周期尚未结算
- 交易还未完成
- 凭证正在生成
- 系统正在同步订单状态
- 当前处于风控保护状态
- 平台数据反馈存在延迟

### 为什么收益和预期不同？

收益会受到市场价格、执行成本、滑点、手续费、资金状态、周期状态和风控规则影响。

收益不是固定数字，也不是无风险承诺。

### 为什么需要查看凭证？

凭证可以帮助用户确认收益来源，理解交易记录，并降低信任成本。

## 风险说明

View Yield 页面展示的是系统记录的收益结果，不代表未来收益保证。

历史收益不代表未来表现。

真实市场交易仍然存在亏损风险，用户应结合风险说明、凭证信息和系统规则理解收益结果。

## 核心结论

View Yield 是 SuperFlow Protocol 的收益展示入口。

它让用户不仅看到收益数字，也能看到收益来源、交易记录、风险状态和验证凭证。

SuperFlow 的目标，是让收益从“展示数字”升级为“可解释、可记录、可验证的系统结果”。
