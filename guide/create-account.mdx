# Create Account

Create Account 是用户进入 SuperFlow Protocol 的第一步。

在 SuperFlow 中，账户不是一个简单登录入口，而是用户身份、资产状态、权限状态、AGENT 使用状态与收益记录的统一载体。

## 核心定义

Account = 用户身份 + 资产状态 + 权限状态 + 系统记录

用户创建账户后，才能进入 SuperFlow 的交易能力系统，并连接 SUPER AGENT、资金系统、收益系统与凭证系统。

## 为什么账户很重要？

SuperFlow 不是一个普通工具页面，而是一个 AI 交易操作系统。

系统需要通过账户识别用户的：

## 创建账户流程

<Steps>
  <Step title="进入 SuperFlow">
    用户通过 SuperFlow 官网或应用入口进入系统。
  </Step>

  <Step title="选择创建账户">
    用户点击注册、创建账户或连接入口，开始创建 SuperFlow 系统账户。
  </Step>

  <Step title="填写基础信息">
    用户填写必要账户信息，例如邮箱、手机号、邀请码或其他系统要求信息。
  </Step>

  <Step title="完成安全验证">
    系统可能要求用户完成验证码、邮箱验证、2FA 或其他安全验证。
  </Step>

  <Step title="进入账户中心">
    账户创建完成后，用户可以进入 Dashboard 查看资产、AGENT、收益和系统状态。
  </Step>
</Steps>

## 账户创建后能做什么？

创建账户后，用户可以逐步使用以下功能：

| 功能 | 说明 |
| --- | --- |
| Deposit Assets | 充值 BTC、ETH、USDT、USDC、SUPER 等资产 |
| Activate SUPER AGENT | 启用 SUPER AGENT 交易能力 |
| View Yield | 查看收益、周期收益、历史收益与收益率 |
| Verify Records | 查看交易凭证、订单记录与收益验证信息 |
| Manage Permission | 查看账户等级、权限状态与系统参与深度 |
| Withdraw Assets | 根据系统规则进行资产提现 |

## 账户与 SUPER AGENT 的关系

用户账户是连接 SUPER AGENT 的入口。

```text
用户创建账户
  ↓
资金进入账户
  ↓
权限状态被识别
  ↓
SUPER AGENT 获得可调度条件
  ↓
系统进入交易能力流程
```

没有账户，系统无法识别用户资金、权限、收益记录和凭证数据。

因此，账户是 SuperFlow 系统的基础入口。

## 账户与资金系统的关系

在 SuperFlow 中，资金不是静态余额，而是可被系统识别和调度的资源。

当用户完成充值后，Capital System 会读取：

- 资产类型
- 充值数量
- 可用余额
- 参与周期
- 权限状态
- 风险状态
- 收益记录

这些信息会影响 SUPER AGENT 的执行条件和收益系统的记录方式。

## 安全建议

用户创建账户后，应注意账户安全。

建议：

- 使用安全密码
- 开启 2FA 验证
- 不向他人泄露账户信息
- 不向任何人泄露私钥、验证码或安全码
- 确认访问的是 SuperFlow 官方地址
- 谨慎识别钓鱼网站和假冒客服

## 风险说明

创建账户不代表收益保证。

账户只是用户进入 SuperFlow 系统的入口。

真实交易仍然存在市场风险、执行风险、流动性风险、系统风险和本金亏损风险。

用户在使用 SuperFlow 前，应理解项目机制、收益来源、风险边界与系统规则。

## 核心结论

Create Account 是用户进入 SuperFlow Protocol 的第一步。

账户不是简单登录信息，而是连接用户身份、资金状态、权限状态、SUPER AGENT、收益系统和凭证系统的基础载体。
