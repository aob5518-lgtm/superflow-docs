# Activate SUPER AGENT

Activate SUPER AGENT 是用户正式进入 SuperFlow AI 交易能力系统的关键步骤。

在 SuperFlow 中，SUPER AGENT 不是一个普通交易机器人，而是一个由决策引擎、执行调度器与风险控制系统组成的 AI 交易执行体。

用户启用 SUPER AGENT 后，账户资金、权限状态、风险状态与系统规则会进入统一调度流程。

## 核心定义

Activate SUPER AGENT = 启用 AI 决策能力 + 连接资金状态 + 进入系统调度流程

它的目标，是让用户不再直接面对复杂交易操作，而是进入由 SUPER AGENT、Smart Routing、Execution Layer、Yield System 和 Verification System 共同组成的交易能力系统。

## 启用前需要什么？

用户启用 SUPER AGENT 前，需要先完成基础准备。

| 条件 | 说明 |
| --- | --- |
| Account | 用户需要拥有 SuperFlow 系统账户 |
| Deposit | 用户需要完成资产充值 |
| Permission | 用户需要满足系统权限、等级或参与条件 |
| Risk Confirmation | 用户需要理解市场风险和系统风险 |
| Supported Assets | 用户需要使用系统支持的资产，例如 BTC、ETH、USDT、USDC、SUPER |
| Security Setup | 建议完成密码、邮箱、2FA 等安全设置 |

## 启用流程

<Steps>
  <Step title="进入账户中心">
    用户登录 SuperFlow 后，进入 Dashboard、AGENT 页面或系统控制台。
  </Step>

  <Step title="查看账户状态">
    系统会显示用户资产、权限、AGENT 状态、参与周期和风险提示。
  </Step>

  <Step title="选择启用 SUPER AGENT">
    用户点击启用、激活或进入 SUPER AGENT 的相关按钮。
  </Step>

  <Step title="确认参与规则">
    用户需要确认系统机制、收益来源、风险说明、周期规则和相关限制。
  </Step>

  <Step title="系统检查条件">
    SuperFlow 会检查账户余额、权限状态、资金状态、风险状态和可执行条件。
  </Step>

  <Step title="启用成功">
    启用成功后，SUPER AGENT 会进入账户的系统调度流程。
  </Step>
</Steps>

## SUPER AGENT 的执行链路

SUPER AGENT 启用后，并不是直接无条件下单。

交易意图需要经过系统链路：

```text
Account State
  ↓
Capital State
  ↓
SUPER AGENT
  ↓
Risk Control
  ↓
Smart Routing
  ↓
Execution Layer
  ↓
Yield System
  ↓
Verification System
```

这个流程的意义是：交易不是一个按钮，而是一套系统化执行过程。

## 用户能看到什么？

启用 SUPER AGENT 后，用户可以在账户页面或 AGENT 页面查看：

| 页面信息 | 说明 |
| --- | --- |
| AGENT Status | SUPER AGENT 当前状态，例如未启用、运行中、暂停中 |
| Available Capital | 当前可参与系统调度的资金 |
| Yield Data | 当前收益、历史收益、周期收益和收益率 |
| Risk Status | 当前风险状态、风控触发和异常提示 |
| Execution Records | 历史交易、订单状态和执行结果 |
| Verification Records | 收益凭证、交易凭证和查询链接 |

## AGENT 状态说明

SUPER AGENT 可能存在不同状态。

| 状态 | 说明 |
| --- | --- |
| Inactive | 未启用 |
| Activating | 正在启用或系统检查中 |
| Active | 已启用并进入系统调度流程 |
| Monitoring | 正在监控市场、账户和风险状态 |
| Executing | 正在执行交易任务 |
| Paused | 因用户操作、风控或系统原因暂停 |
| Protected | 因异常行情、平台状态或风险触发进入保护状态 |
| Stopped | 已停止或退出参与 |

## 启用 SUPER AGENT 不等于固定收益

这是非常重要的边界。

SUPER AGENT 是交易决策与执行调度系统，不是固定收益产品。

它可以帮助用户：

- 降低操作门槛
- 提升执行效率
- 进行系统化风控
- 记录交易结果
- 生成收益凭证
- 优化交易路径

但它不能保证每一次交易都盈利，也不能保证固定收益率。

真实市场交易仍然存在本金亏损风险。

## 与 Smart Routing 的关系

SUPER AGENT 负责生成交易意图。

Smart Routing 负责判断如何执行交易意图。

```text
SUPER AGENT = 是否交易、交易逻辑、交易意图
Smart Routing = 在哪里执行、如何执行、以什么成本执行
Execution Layer = 提交订单、同步状态、记录结果
```

## 与 Yield System 的关系

SUPER AGENT 参与收益形成，但收益最终由真实市场结果决定。

Yield System 会根据执行结果记录：

## 与 SUPER Token 的关系

SUPER Token 可以连接 SUPER AGENT 的系统权限与参与深度。

根据系统设计，SUPER Token 可能影响：

- AGENT 使用权限
- 系统参与等级
- 账户权限状态
- 收益权重
- 周期参与深度
- 节点或生态身份
- 长期激励关系

这意味着 SUPER Token 是用户进入更深层系统能力的重要连接资产。

## 安全建议

启用 SUPER AGENT 前，用户应确认：

- 已理解系统机制
- 已阅读风险说明
- 已确认参与资产
- 已确认参与周期
- 已确认账户安全
- 不使用生活必需资金参与高风险交易
- 不把验证码、私钥、助记词泄露给任何人

## 风险说明

启用 SUPER AGENT 不代表收益保证。

真实交易存在：

- 市场波动风险
- 执行失败风险
- 滑点风险
- 流动性风险
- 策略失效风险
- 平台异常风险
- 系统风险
- 本金亏损风险

SUPER AGENT 的价值是系统化决策、执行调度和风险控制，而不是消除市场风险。

## 核心结论

Activate SUPER AGENT 是用户进入 SuperFlow 交易能力系统的关键步骤。

启用后，用户账户会连接 AI 决策、资金调度、智能路由、真实执行、收益记录和交易凭证系统。

SUPER AGENT 不是固定收益工具，而是 SuperFlow Protocol 的核心 AI 交易执行体。
