# Risk Disclosure

本风险披露适用于 SuperFlow Protocol 相关网站、文档、产品说明、用户界面、社群内容、市场资料、合作资料及其他公开信息。

用户在访问、使用或参与 SuperFlow Protocol 前，应充分理解数字资产、自动化交易、AI 决策系统、交易执行系统和 SUPER Token 相关风险。

## 核心声明

SuperFlow Protocol 是一个 AI-Driven Trading Operating System。

它通过 SUPER AGENT、Smart Routing、Execution Layer、Yield System、Verification System 和 SUPER Token 等模块，将交易能力抽象为系统能力。

但任何涉及真实市场交易、数字资产、自动化执行和代币参与的行为，都存在风险。

SuperFlow 不承诺固定收益，不保证本金安全，不保证未来收益，不构成投资建议。

## 市场风险

数字资产市场具有高波动性。

价格可能在短时间内大幅上涨或下跌，市场可能出现：

- 极端波动
- 流动性不足
- 快速插针
- 价格断层
- 深度不足
- 大额资金冲击
- 趋势反转
- 黑天鹅事件

即使 SUPER AGENT 能够识别部分市场状态，也无法保证每一次判断都正确。

市场风险可能导致交易亏损，甚至本金损失。

## 自动化交易风险

SuperFlow 使用 AI 决策、系统调度和自动化执行能力。

自动化交易可以提升效率，但也存在风险：

| 风险 | 说明 |
| --- | --- |
| 参数风险 | 参数设置不适合当前市场环境 |
| 策略风险 | 策略在某些行情中可能失效 |
| 连续执行风险 | 系统连续执行可能放大错误结果 |
| 状态同步风险 | 账户、订单或仓位状态同步不及时 |
| 自动化误判 | 系统可能基于错误数据或异常状态执行 |
| 用户配置风险 | 用户错误配置可能影响系统行为 |

自动化并不代表无风险。

## AI 决策风险

SUPER AGENT 是 SuperFlow 的核心 AI 交易执行体，但 AI 决策不等于绝对正确。

AI 系统可能受到以下因素影响：

<CardGroup cols={2}>
  <Card title="数据质量" icon="activity">
    如果市场数据、账户数据或订单数据异常，AI 判断可能受到影响。
  </Card>

  <Card title="市场变化" icon="chart-line">
    市场环境快速变化时，历史模型或当前判断可能失效。
  </Card>

  <Card title="执行延迟" icon="zap">
    AI 生成交易意图后，实际执行可能受到延迟、滑点和平台状态影响。
  </Card>

  <Card title="风险误判" icon="shield">
    系统风控可以限制风险，但不能完全避免所有风险事件。
  </Card>
</CardGroup>

用户应理解：

```text
AI 可以辅助决策，但不能保证盈利。
AI 可以提升效率，但不能消除风险。
AI 可以参与风控，但不能保证本金安全。
```

## 执行风险

SuperFlow 的交易执行依赖 Execution Layer 和相关执行环境。

在真实市场中，订单执行可能出现：

- 下单失败
- 成交失败
- 部分成交
- 成交延迟
- 滑点过高
- 订单被拒绝
- 平台限制
- 保证金不足
- 余额不足
- 最小下单数量限制
- API 返回异常
- 状态同步失败

这些情况可能影响最终交易结果和收益记录。

## 流动性风险

流动性不足可能导致用户无法以预期价格成交。

当市场深度不足、交易量下降或极端行情发生时，可能出现：

| 情况 | 影响 |
| --- | --- |
| 深度不足 | 大额订单可能产生明显滑点 |
| 买卖盘稀薄 | 成交价格可能偏离预期 |
| 市场快速波动 | 订单执行价格可能与预期不同 |
| 平台流动性变化 | 不同平台之间的价格和深度可能差异较大 |

Smart Routing 可以尝试优化执行路径，但不能保证完全避免流动性风险。

## 系统技术风险

SuperFlow 是一个由多个模块组成的系统。

系统可能受到技术因素影响，包括：

| 风险 | 说明 |
| --- | --- |
| Server Risk | 服务器故障、资源不足、服务中断 |
| Network Risk | 网络延迟、连接失败、DNS 或防火墙问题 |
| API Risk | API 断连、限频、返回异常或数据不一致 |
| Code Risk | 程序错误、逻辑错误、配置错误 |
| Database Risk | 数据记录异常、同步失败或丢失 |
| Security Risk | 账户攻击、私钥泄露、权限被盗用 |
| Upgrade Risk | 系统升级可能导致短期不稳定 |

任何技术系统都不可能完全避免故障。

## 风控系统边界

Risk Control 是 SuperFlow 的系统化风控机制。

它可以识别和限制部分风险，例如：

- 仓位过高
- 连续亏损
- 保证金不足
- 余额不足
- 异常行情
- 平台异常
- 执行失败
- API 异常
- 状态不同步

但风控系统不能保证完全避免亏损。

风控的作用是：

```text
识别风险
限制风险
记录风险
反馈风险
```

而不是消除所有风险。

## 收益风险

Yield System 展示的是收益记录和收益结果。

但收益记录不代表未来表现。

用户应理解：

- 历史收益不代表未来收益
- 当前收益不代表最终收益
- 收益率可能波动
- 收益可能变为亏损
- 周期收益可能受到市场和执行影响
- 凭证记录只说明历史结果，不代表未来承诺

SuperFlow 不应被理解为固定收益系统。

## 凭证验证风险

Verification System 可以提高透明度，但它也存在边界。

不同平台支持的验证方式不同：

| 平台类型 | 风险与边界 |
| --- | --- |
| 链上交易 | 可通过 Tx Hash 查询，但链上确认可能延迟 |
| Hyperliquid 类平台 | 公开查询能力取决于平台浏览器和地址记录 |
| Extended 类平台 | 可能需要平台订单号、成交号或账户历史核验 |
| CEX 类平台 | 通常无法完全公开查询，需要账户历史或授权记录 |
| 内部凭证 | 依赖 SuperFlow 系统记录和数据完整性 |

凭证系统提高透明度，但不代表收益保证。

## 监管与合规风险

不同国家和地区对数字资产、自动化交易、AI 交易系统、代币发行、收益展示、金融服务和相关活动可能存在不同法律法规。

用户应自行确认其所在地区是否允许访问、使用或参与相关服务。

监管风险可能导致：

- 服务限制
- 功能调整
- 访问限制
- 用户参与限制
- 资产或交易规则变化
- 文档、产品或业务模型调整

用户应自行承担地区合规判断责任。

## 用户操作风险

用户自身操作也可能造成损失。

常见用户操作风险包括：

| 风险 | 说明 |
| --- | --- |
| 地址错误 | 充值或提现地址错误可能导致资产丢失 |
| 网络错误 | 选择错误链或错误网络可能导致资产无法到账 |
| 私钥泄露 | 泄露私钥、助记词、验证码可能导致账户被盗 |
| 钓鱼网站 | 访问假冒网站可能造成资产损失 |
| 配置错误 | 错误设置账户、周期、权限或交易参数 |
| 误解机制 | 未充分理解收益、风险和系统规则即参与 |

用户应谨慎操作，并保护账户和资产安全。

## 不适合参与的情况

以下用户不建议参与或使用 SuperFlow 相关服务：

- 无法理解数字资产风险的用户
- 无法承受本金亏损的用户
- 使用生活必需资金参与的用户
- 期待固定收益或保本收益的用户
- 所在地区法律不允许相关服务的用户
- 未充分理解 SuperFlow 机制和风险的用户

## 核心结论

SuperFlow Protocol 是一个 AI 驱动的交易能力系统，但不代表无风险收益系统。

真实交易存在市场风险、执行风险、系统风险、平台风险、代币风险和监管风险。

用户应在充分理解风险的前提下谨慎参与，并自行承担相关风险。
