# FAQ

FAQ 用于回答用户、代理、合作方和早期参与者最常见的问题。

SuperFlow Protocol 是一个 AI-Driven Trading Operating System，不是普通交易工具，也不是单一策略平台。理解 SuperFlow，需要从系统、资金、SUPER AGENT、收益、风险、SUPER Token 和交易凭证几个方面来看。

## SuperFlow 是什么？

SuperFlow Protocol 是一个 AI 驱动的链上交易能力系统。

它将账户系统、资金系统、SUPER AGENT、Smart Routing、Execution Layer、Yield System、Verification System 和 SUPER Token 整合为一个统一的交易能力基础设施。

一句话定义：

> We do not provide trading tools.  
> We provide trading capability.

## SuperFlow 和普通交易平台有什么区别？

普通交易平台主要提供交易入口。

SuperFlow 的目标不是再做一个简单交易入口，而是将交易能力系统化。

| 对比项 | 普通交易平台 | SuperFlow Protocol |
| --- | --- | --- |
| 核心定位 | 交易入口 | AI 交易能力系统 |
| 用户行为 | 用户自己判断和操作 | 系统辅助决策与执行调度 |
| 执行方式 | 用户手动下单 | SUPER AGENT + Smart Routing + Execution Layer |
| 收益展示 | 页面数字展示 | 收益记录 + 交易凭证 + 验证入口 |
| 风控方式 | 依赖用户经验 | 系统化风控机制 |
| 代币作用 | 可能只是支付或积分 | 系统控制权、行为驱动工具与系统稳定器 |

## SUPER AGENT 是什么？

SUPER AGENT 是 SuperFlow Protocol 的核心 AI 交易执行体。

它由三个核心部分组成：

```text
SUPER AGENT = 决策引擎 + 执行调度器 + 风控系统
```

SUPER AGENT 不是简单喊单工具，也不是固定收益机器。它的本质是 AI 决策与执行调度系统，用于识别市场状态、账户状态、资金状态、风险状态，并连接 Smart Routing 与 Execution Layer 完成真实执行。

## SUPER AGENT 会保证收益吗？

不会。

SUPER AGENT 不是固定收益产品，也不承诺每一笔交易都盈利。

它可以帮助用户：

## 收益来自哪里？

SuperFlow 的收益来自真实市场行为。

收益形成流程可以理解为：

```text
资金进入系统
  ↓
SUPER AGENT 识别机会
  ↓
Smart Routing 优化路径
  ↓
Execution Layer 完成真实交易
  ↓
Yield System 记录收益
  ↓
Verification System 生成凭证
```

收益不是平台简单分配出来的，也不是无风险固定收益。

## 收益如何计算？

SuperFlow 的收益不是只由本金决定，而是受到多个变量影响。

```text
收益 = 资金 × 时间 × 权限 × 市场能力 × 执行质量 × 风控能力
```

其中包括：

| 变量 | 说明 |
| --- | --- |
| 资金 | 用户参与资金规模 |
| 时间 | 用户参与周期和资金持续时间 |
| 权限 | 用户账户等级、SUPER Token 状态与系统参与深度 |
| 市场能力 | 系统识别交易机会的能力 |
| 执行质量 | 智能路由、滑点控制和执行稳定性 |
| 风控能力 | 系统控制回撤、异常和执行失败的能力 |

## SuperFlow 是否有风险？

有。

任何真实交易系统都存在风险。

## SUPER Token 是什么？

SUPER Token 是 SuperFlow Protocol 的系统代币。

它不是简单支付工具，也不是普通平台积分，而是：

```text
SUPER Token = 系统控制权 + 行为驱动工具 + 系统稳定器
```

它可以连接系统权限、SUPER AGENT 使用深度、收益权重、长期激励、回购销毁和生态扩展。

## SUPER Token 有什么用途？

SUPER Token 的主要用途包括：

| 用途 | 说明 |
| --- | --- |
| 系统权限 | 连接账户等级、功能权限和参与深度 |
| AGENT 能力 | 连接 SUPER AGENT 的使用权限和能力等级 |
| 收益权重 | 与参与周期、资金状态和权限状态共同影响收益权重 |
| 行为激励 | 激励持有、锁定、节点、推广和生态贡献 |
| 价值反馈 | 与回购、销毁、激励和系统飞轮连接 |
| 生态扩展 | 连接 Supermarket、Super EVM 和合作方接入 |

## Buyback & Burn 是什么？

Buyback & Burn 是 SUPER Token 的价值反馈机制之一。

当 SuperFlow 系统产生交易收入、生态收入或合作收入后，可以将部分系统价值反馈到 SUPER Token，通过回购、销毁、锁定、储备或激励形成长期价值结构。

但需要注意：

> 回购销毁不代表价格保证，也不代表收益承诺。

## Verification System 是什么？

Verification System 是 SuperFlow 的交易凭证与收益验证系统。

它用于记录和展示：

- 交易资产
- 交易方向
- 开仓价格
- 平仓价格
- 成交数量
- 盈亏结果
- 收益率
- 平台订单号
- 平台成交号
- 链上哈希
- 查询链接
- 平仓原因
- 凭证状态

它的目标是让用户不仅看到收益数字，还能理解收益来源和验证路径。

## 为什么要做交易凭证？

因为交易系统的信任不应该只靠宣传。

交易凭证可以帮助用户回答：

```text
这笔收益来自哪笔交易？
在哪个平台执行？
开仓价是多少？
平仓价是多少？
盈亏是多少？
是否有订单号？
是否有成交号？
是否有查询链接？
为什么平仓？
是否触发风控？
```

凭证系统的作用是提高透明度，而不是保证未来收益。

## SuperFlow 是否支持合作方接入？

SuperFlow 可以通过公开接口或授权接口，为合作方提供交易凭证、收益记录或系统数据读取能力。

例如：

```text
/api/public/profit-vouchers
```

该接口可以用于第三方平台、代理后台、客户系统或合作方展示公开收益凭证数据。

## SuperFlow 和 Hyperliquid 有什么关系？

SuperFlow 可以参考高性能链上交易基础设施的设计理念，但 SuperFlow 的定位不是复制某一个交易平台。

SuperFlow 的核心定位是：

```text
AI-Driven Trading Operating System
```

它强调的是 SUPER AGENT、智能路由、执行层、收益系统、凭证系统和 SUPER Token 之间形成统一系统。

## SuperFlow 是否是 DeFi？

SuperFlow 可以连接链上资产、交易执行、AI 决策和系统代币，但它不应该被简单理解为单一 DeFi 产品。

更准确的定位是：

> AI 驱动的链上交易能力基础设施。

## 用户需要自己交易吗？

SuperFlow 的目标，是减少普通用户直接面对复杂交易操作的压力。

用户进入系统后，可以通过账户、资金、权限和 SUPER AGENT 连接交易能力系统。

但用户仍然需要理解机制、确认风险，并对自己的参与行为负责。

## 可以在哪里查看收益？

用户可以在 View Yield 页面查看：

- 当前收益
- 历史收益
- 收益率
- 参与资金
- 周期状态
- AGENT 状态
- 风险状态
- 收益凭证

完整收益记录应该与 Verification System 连接。

## 可以在哪里验证收益？

用户可以在 Verify Records 页面查看收益凭证。

如果平台支持外部核验，用户可以通过订单号、成交号、Tx Hash 或查询链接进一步验证。

如果平台不支持公开查询，则可以通过 SuperFlow 凭证页面、系统记录或合作方接口进行核验。

## 历史收益代表未来收益吗？

不代表。

历史收益只代表过去系统记录的结果，不代表未来表现。

真实交易仍然存在市场变化、系统变化、执行变化和本金亏损风险。

## SuperFlow 的最终目标是什么？

SuperFlow 的目标，是让交易能力成为可以被系统调用、组合、调度和验证的基础能力。

最终表达是：

> If Ethereum made value programmable, SuperFlow makes trading capability programmable.

## 核心总结

SuperFlow Protocol 不是普通交易工具。

它是一个由 SUPER AGENT、Smart Routing、Execution Layer、Yield System、Verification System、SUPER Token 和未来生态模块共同组成的 AI 交易能力系统。

用户进入 SuperFlow，不只是进入一个交易页面，而是进入一个系统化交易能力网络。
