# Brand Assets

Brand Assets 是 SuperFlow Protocol 的品牌素材与视觉规范页面。

它用于统一 SuperFlow 的 Logo、SUPER AGENT IP 形象、品牌色、项目定位、核心口号、视觉风格和对外传播素材，确保官网、Docs、PPT、海报、社群、视频和合作方资料保持一致。

## 核心定义

Brand Assets = Logo + IP 形象 + 品牌色 + 项目定位 + 传播规范 + 素材下载

它的目标，是让 SuperFlow 在所有对外场景中保持统一、专业、高级和可信的品牌表达。

## 品牌名称

SuperFlow 的项目名称应统一使用：

```text
SuperFlow Protocol
```

在正式文档、官网、白皮书、PPT 和媒体资料中，建议优先使用完整名称。

可接受简称：

```text
SuperFlow
```

不建议随意使用其他缩写或旧名称。

## 核心定位

SuperFlow Protocol 的核心定位是：

```text
AI-Driven Trading Operating System
Built on High-Performance Execution Infrastructure
```

中文表达：

```text
AI 驱动的链上交易操作系统
构建于高性能交易执行基础设施之上
```

## 一句话定位

SuperFlow 的一句话定位是：

> We do not provide trading tools.  
> We provide trading capability.

中文表达：

> 我们不提供交易工具。  
> 我们提供交易能力。

## 核心系统定义

SuperFlow 是一个将交易能力抽象为系统能力的链上操作系统。

它将账户系统、资金系统、SUPER AGENT、Smart Routing、Execution Layer、Yield System、Verification System、SUPER Token 和未来生态模块整合为统一的交易能力基础设施。

## Logo 使用注意事项

使用 Logo 时应避免：

- 拉伸变形
- 低清晰度使用
- 随意改变颜色
- 放在复杂背景上导致识别不清
- 与无关图形混合
- 与旧版项目名称或旧符号混用
- 在正式资料中使用不统一版本

## SUPER AGENT IP 形象

SUPER AGENT 是 SuperFlow 的核心 AI 交易执行体，也是项目的重要视觉 IP。

它的形象应保持统一：

```text

顶部悬浮水滴
```

## SUPER AGENT 的视觉意义

SUPER AGENT 不是普通吉祥物。

它代表 SuperFlow 的 AI 决策、系统调度、风险控制和交易能力。

| 视觉元素 | 含义 |
| --- | --- |
| 白色主体 | 干净、可信、系统化、科技感 |
| 黑色面屏 | AI 识别、智能界面、系统反馈 |
| 蓝色眼睛 | 决策能力、智能感知、友好交互 |
| 水滴元素 | 流动性、交易流、资金流、生命力 |
| 蓝色能量体 | 系统能量、市场流动、AI 算力与执行能力 |

在所有正式文档中，应统一使用以下表达。

## 对外宣传边界

SuperFlow 对外宣传应避免：

- 保证收益
- 承诺固定回报
- 暗示无风险
- 夸大 AI 必然盈利
- 使用无法验证的数据
- 将收益描述为平台内部简单分配
- 混用旧名称
- 用不清晰或低质量视觉素材

推荐表达：

```text
SuperFlow 通过 SUPER AGENT、智能路由、执行层、收益系统和凭证系统，
将复杂交易过程抽象为系统化交易能力。
```

## 核心结论

Brand Assets 是 SuperFlow Protocol 对外统一表达的基础。

它确保项目在官网、Docs、白皮书、PPT、海报、视频、社群和合作方资料中保持一致的品牌识别、视觉语言和项目定位。

SuperFlow 的品牌目标，不是做一个普通交易产品，而是建立一个高级、可信、系统化的 AI 交易能力协议形象。
