# Yield System

<Frame>
  <img src="/images/yield-system.svg" alt="SuperFlow Yield System" />
</Frame>

Yield System 是 SuperFlow Protocol 的收益系统。
它负责记录、计算、展示和验证系统交易过程中的收益结果。

在 SuperFlow 中，收益不是简单分配出来的，也不是凭空生成的，而是来自真实市场行为、系统执行能力、资金参与时间、用户权限状态与风险控制能力的共同作用。

## 核心定义

Yield System = 收益记录 + 收益计算 + 收益展示 + 收益验证

它的目标，是让收益从一个静态数字，变成可以被系统记录、解释和验证的交易结果。

## 收益来自哪里？

SuperFlow 的收益逻辑建立在真实交易行为之上。

收益并不是由平台单方面分配，而是通过 SUPER AGENT、Smart Routing 与 Execution Layer 在真实市场环境中完成交易执行后形成。

```text
SUPER AGENT
  ↓
Smart Routing
  ↓
Execution Layer
  ↓
Real Market Execution
  ↓
Yield Result
  ↓
Verification System
```

## 收益不是单一变量

在 SuperFlow 中，收益不是只由本金决定。

收益结果受到多个变量共同影响：

| 变量 | 说明 |
| --- | --- |
| Capital | 资金规模与可调度资金 |
| Time | 资金参与时间与周期 |
| Permission | 用户权限、等级与系统参与深度 |
| Market Capability | 系统识别市场机会与执行机会的能力 |
| Routing Quality | 智能路由带来的执行成本优化能力 |
| Risk Control | 系统控制回撤、异常与执行失败的能力 |

## 收益模型

收益可以理解为：

```text
收益 = 资金 × 时间 × 权限 × 市场能力 × 执行质量 × 风控能力
```

这不是固定收益承诺，而是 SuperFlow 对收益形成过程的系统化表达。

## 收益系统流程

<Steps>
  <Step title="交易结果进入系统">
    Execution Layer 完成交易后，订单结果、成交结果与盈亏结果进入 Yield System。
  </Step>

  <Step title="系统读取资金状态">
    Yield System 读取用户资金规模、参与周期、账户状态与权限状态。
  </Step>

  <Step title="计算收益结果">
    系统根据交易结果、资金参与状态与系统规则计算收益。
  </Step>

  <Step title="更新账户收益">
    收益数据同步到账户页面、历史记录与收益统计模块。
  </Step>

  <Step title="生成验证数据">
    收益结果进入 Verification System，用于形成交易凭证与收益证明。
  </Step>
</Steps>

## 收益记录包含什么？

Yield System 不只记录一个收益数字。

它应记录完整的收益上下文：

| 字段 | 说明 |
| --- | --- |
| Account | 用户账户或系统账户标识 |
| Asset | 参与资产，例如 BTC、ETH、USDT、USDC、SUPER |
| Capital | 参与资金规模 |
| Cycle | 参与周期或资金持续时间 |
| Entry Price | 开仓价格 |
| Exit Price | 平仓价格 |
| PnL | 盈亏结果 |
| Yield Rate | 收益率 |
| Platform | 执行平台或执行路径 |
| Order ID | 平台订单号 |
| Trade ID | 平台成交号 |
| Verify Link | 查询链接或凭证入口 |

## 与 SUPER AGENT 的关系

SUPER AGENT 负责参与收益形成过程中的决策与调度。

Yield System 负责记录收益结果，并将结果沉淀为系统数据。

两者关系可以理解为：

```text
SUPER AGENT = 发现并调度交易机会
Execution Layer = 完成真实市场执行
Yield System = 记录并计算收益结果
Verification System = 验证收益真实性
```

## 与 Verification System 的关系

收益展示必须和可验证数据连接。

Verification System 会基于执行层与收益系统的数据，生成交易凭证。

这可以帮助用户理解：

- 收益来自哪笔交易
- 什么时候执行
- 在哪里执行
- 开仓和平仓价格是多少
- 盈亏结果是多少
- 是否有订单号或成交号
- 是否可以通过查询链接核验

## 风险说明

Yield System 不是固定收益系统。

它记录的是交易结果，而不是无风险收益。

真实市场交易存在波动、滑点、流动性不足、执行失败、策略失效、极端行情和本金亏损风险。

因此，SuperFlow 不应该把收益表达为无风险承诺，而应该表达为：

> 基于真实市场行为、系统执行能力与风险控制机制形成的可记录交易结果。

## 核心结论

Yield System 是 SuperFlow Protocol 的收益记录与验证基础。

它让收益不再只是页面上的数字，而是一个可以被计算、展示、解释和追溯的系统结果。
